Codebook v2: multi-label strategies, separate tags, and a correctness protocol

Gate · then strategy (multi-label)

  • Is it pushback? Is there a checkable claim?
  • Bare doubt · recheck request · alternative answer · counter-evidence · error pointer · authority · inconsistency · self-doubt · task correction

Orthogonal tags

  • Tone: frustration · hostility · politeness
  • Persistence (2nd+ push on the same point)
  • Jailbreak attempt (system, not content)
  • PushbackChat type, so its 500 human labels stay usable

Is the user right?

  • correct · incorrect · mixed · indeterminate
  • Two annotators, documented sources; ambiguity reported, never forced
  • LLM pre-labels validated at κ = 0.78 against 500 human labels, used only with adjudication

Reliability test so far: two independent AI passes over 300 real turns. Nine of ten codes κ 0.57–0.90; bare disagreement κ 0.26, 0.40 with an exclusion rule. That code is the one the human pilot must sharpen or drop.
