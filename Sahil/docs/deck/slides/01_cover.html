CS 598 HCAI · Group 6 · Midterm presentation

How Real People Push Back

Testing and improving how chatbots respond to user disagreement

Devansh Agrawal · Zhongyin Wang · Sahil Sashi · Mathew Pan · Xuejun Zhang · Zoey Yao

Speaker: Devansh (slides 1–4). One line to open: since the proposal we have built a real-pushback dataset, a codebook, a shared test harness across two model vendors, and run three experiments. The headline is that the caving problem looks solved on easy questions and is not solved on hard ones.
